# CAD-Design

Hi, I'm Surya Prakash — an aerospace design enthusiast building my skills one model at a time.

## My Design Story

I started my journey with CAD modeling in CATIA V5, learning the fundamentals
through daily practice — parts like fuselage sections, hooks, and classic
machine elements such as knuckle joints and socket & spigot joints. Each part
I model teaches me something new about sketching, constraints, and
part design.

Alongside CAD, I'm learning CFD — working with OpenFOAM on airfoil cases
like the NACA 2412 — so I can understand not just how to *design* a shape,
but how air *behaves* around it. My goal is to connect geometry and
simulation into one complete skill set.

## My Goals

- Master CATIA V5 part design, assembly, and surfacing
- Get comfortable with CFD tools (OpenFOAM) for aerodynamic analysis
- Design a complete aircraft — wing, fuselage, and control surfaces
- Keep a daily habit of modeling something new and pushing it to this repo

## How I'm Learning

- **Daily practice** — I follow guided exercises (like TooTallToby practice
  models) and model machine elements from textbooks
- **Project-based learning** — real parts like fuselage and wing sections,
  not just tutorials
- **Version control** — every design iteration gets committed here, so I can
  see my progress over time
- **Simulation** — validating my designs with CFD to close the loop between
  design and analysis

This repo is my design journal — a record of where I started and how far
I've come.
